# Udentify v25.4.0

{% hint style="success" %}
&#x20;**Release date : 19/01/2026**
{% endhint %}

### 1. Breaking Changes

* **UdentifyRest**
  * IQA v2 includes non-compatible updates to previous REST IQA behavior.
* **Android OCR SDK**
  * Updated ML Kit dependencies: Replaced `face-detection` and `object-detection` with `play-services-mlkit-face-detection` and updated versions.
  * Added new signature: `void onOCRDirectiveChanged(OCRDirective directive);`.
  * Added cropped review screen photos with `cardScanFinished` callback.
  * Updated `onIqaResult` method signature.
  * Updated `CardRecognizerObject` constructor to require `Activity`.
  * Added new signature: `void onHologramDirectiveChanged(HologramDirective directive);`.
* **Android FACE SDK**
  * Updated dependency: Removed `mlkit:face-detection` and added `play-services-mlkit-face-detection`.
* **React Native liveness-rn-library**
  * Android ecosystem dependencies (`tensorflow-lite`, `tensorflow-lite-gpu`, `tensorflow-lite-support`, `play-services-mlkit-face-detection`, `okhttp`, `okhttp-tls`, `cameraview`, `material`, `gson`, `lottie`, and AndroidX) are now `compileOnly`. The host application must provide them as `implementation` in its own `android/app/build.gradle`. This prevents dependency version conflicts and silent "highest wins" overrides when the host app uses other ML or networking libraries.
  * Migration: copy the dependency block from `liveness-rn-library/README.md` → "Required Host App Dependencies" into your `android/app/build.gradle`. No JavaScript API changes.
* **iOS OCR SDK**
  * `OCRCameraControllerDelegate` and `HologramCameraControllerDelegate` now require implementing `onOCRDirectiveChanged(_: )` and `onHologramDirectiveChanged(_:)`.
  * `onDocumentScan` method signature changed to include `croppedImages: (front: UIImage?, back: UIImage?)` parameter.
  * `OCRCameraControllerDelegate.onIqaResult` now includes an extra parameter: `func onIqaResult(for: OCRDocumentSide, iqaFeedback: IQAFeedback, iqaResponse: IQAResponse?)`.
* **IQA Service**
  * New request/response structure to support passive mode and unified module tautology.

### 2. New Features

#### Breaking Changes

* **UdentifyRest:** Introduced IQA v2 with major breaking changes.
* **Android OCR SDK:** Multiple updates including new directives, IQA improvements, UI adjustments, and placeholders.
* **Android FACE SDK:** Improved liveness UI, added feedback and sound effects.
* **iOS OCR SDK:**
  * Expose OCR & hologram directives for client-side TTS;
  * Add cropped images to document scan callback;
  * Add non-UI IQA API and extend delegate with detailed IQA response.
* **IQA Service:** Added new detection modules, passive mode, and improved processing capabilities for v25.4.0.

#### Server & Backend

* **UdentifyRest**
  * Simplified environment configuration by moving static configs into the Dockerfile and removing default values from properties.
  * Implemented parallel processing for OCR ID operations.
  * Added document number as TCKN to the event list response.
  * Included child transaction activities in parent transaction event detail reports.
  * Implemented to add and configure SessionDirective.
  * Updated the user refresh token service response and added TCKN support to advanced search.
  * Added creation date to the getVideoCallScreenShot response.
  * Implemented the **contains** operator for advanced search.
  * Added a delete-user endpoint and filtered out deleted users from list queries.
  * Added expected answer support to checklist options.
  * Implemented an unsecured video call file fetch service using API keys.
  * Added a parameter to disable binary media data in getTransactionData responses.
  * Implemented concurrent login prevention and active session management.
  * Enabled lazy loading of media in event detail responses.
  * Separated OCR similarity thresholds for improved accuracy.
  * Added audit logging for failed login attempts.
  * Introduced an IQA Audit Log table and persisted IQA media for every attempt.
  * Implemented CRUD operations for session directives and sorted checklist options.
  * Added GetTransactionMediaVideoCallVideo functionality.
  * Added Document Liveness data to transaction details service response.
  * Added NFC passive and active authentication statuses to transaction detail service responses.
* **OCR Service**
  * Added issued\_by field for TRID cards and fix upside-down cropping issue for v25.4.0.
* **FACE Service**
  * Adjust detection thresholds for improved face detection accuracy for v25.4.0.
* **IQA Service**
  * **Detection Modules:** Added chip detector, signature & hidden-photo detector modules.
  * **Error Handling:** Returns error after card classifier when photo is not visible on front-side; returns error when multiple documents detected.
  * **Glare Module:** Added new glare module with optimized thresholding and improved accuracy.
  * **Passive Mode:** Introduced passive modes for modules 2–7, allowing continued processing even when previous modules fail; added new 1001 response code for faulty images in passive mode.
  * **Rotated Images:** Enabled successful processing of slightly rotated images.
* **Liveness Service**
  * Upgrade runtime, integrate APM, and add hand-near-face detection module for v25.4.0.

    * Adjusted `VerificationLabelStyle`.
    * Added `VerificationAnimationStyle` with support for custom Lottie animations.
* **App Demo**

    * Improved support for devices with notches.

    * Updated settings menu and API/URL configurability.

#### iOS
